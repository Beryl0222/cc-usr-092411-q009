# 银龄多形态课程中断接续与支持迁移服务

本仓库保存领域事件契约，以及基于事件溯源实现的中断接续服务：学员短期住院后
可从面授班转到电话辅导，系统不重算候补顺序、不重复占用补贴名额、不把住院前
完成的练习当作未完成。

## 模块

- `contracts/domain.schema.json`：领域事件信封、聚合类型与全部事件名称。
- `data/sample.json`：可用于联调的中文样例记录。
- `src/validator.py`：事件信封的基础字段校验。
- `src/continuity/`：中断接续领域服务。
  - `clock.py`：可冻结、可推进的业务时钟，所有截止点与“课次是否已发生”只经它判定。
  - `events.py` / `journal.py`：不可变事件与仅追加的 JSONL 事件日志，重启即重放恢复。
  - `models.py`：读模型与事件折叠，支持按历史时点（`occurred_at <= as_of`）重建状态。
  - `service.py`：应用服务与全部业务规则。
- `tests/`：信封契约测试与全流程场景测试。

## 业务规则

1. **固定条款**：课程发布时固定教师资历、容量、可提供支持与课次表；更正只能追加事件。
2. **席位与候补**：报名结合学员时段与辅助需求决定正式席位或候补位置；候补序号报名时
   一次确定，暂停、迁移都不会重算。课程无法提供所需支持时拒绝降级接收。
3. **暂停冻结**：暂停只冻结暂停时刻之后尚未发生的课次；已完成课次、练习成果、
   候补优先级、补贴权益全部保留。
4. **守恒迁移**：兼容课程只承接剩余课次（可分批）；补贴权益随报名链原子过户
   （`SUBSIDY_RELINKED`），全程一份权益，不在目标课程重复占名额；高支持需求
   不会因迁移自动降级。待确认方案会预留目标席位与课次，拒绝或过期自动释放。
5. **变更确认**：教师变更或课程取消生成带差异说明的方案，由学员本人或当时有效的
   授权照护人确认。两方同时提交不同选择时进入**待核**（`PROPOSAL_DISPUTED`），
   任何一方都不能抢先覆盖，由教务裁决。
6. **可控时钟**：候补提升截止点、方案确认期限由业务时钟驱动（`tick`）。
7. **幂等重放**：签到与电话确认等命令携带幂等键；同键同内容按重放空转，
   同键不同内容按冲突拒绝（重复签到不会把已完成练习/出勤改回未完成）。
8. **历史时点查询**：可按任意历史时点查询课程归属、支持决定与权益余额。

## 本地检查

```bash
python3 -m unittest discover -s tests
python3 -m compileall -q src tests
```

不需要外部基础设施；事件日志默认内存模式，传入文件路径即获得 JSONL 持久化与
服务重启恢复。
