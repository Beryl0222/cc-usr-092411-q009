# 银龄多形态课程中断接续服务

面向短期住院等中断场景：学员从面授班暂停后可接续到电话辅导，系统保留
候补顺序、补贴权益与已有成果，不重算、不重复占用、不把已完成练习清零。

## 领域规则

- **发布即固定**：课程发布时固定教师资历、容量、可提供支持与补贴名额；
  更正只能产生后继事件，不原地改写。
- **报名决定**：结合学员可用时段与辅助需求决定正式席位或候补；座位与补贴
  名额任一不足即进入候补，候补位置按到达顺序固定，任何后来者都不重排。
- **暂停只冻结未来**：暂停冻结尚未发生的课次；席位/候补位置、补贴名额、
  住院前完成的练习与优先级全部保留。
- **兼容承接**：兼容课程承接剩余课次，支持**分批迁移**；补贴权益守恒
  （源释放 = 目标承接，台账逐批留痕），高支持需求不因迁移自动降级，
  已完成成果随承接报名带入。
- **变更方案**：教师变更或课程取消时生成带差异说明（教师资历、模式、
  支持、补贴前后对比）的方案，由学员本人或**当时有效**的授权照护人确认。
- **并行不覆盖**：学员与照护人同时提交不同选择时方案进入**待核**，
  两方意见都保留，由教务核决；任一方都不能抢先覆盖。
- **可控时钟**：候补提升与确认期限只看业务时钟（`Clock`），不读墙钟。
- **内容判定重放**：重复签到与重复电话确认按业务内容判重，与事件标识、
  递送时间无关。
- **历史时点查询**：`service.state(as_of=...)` 按历史时点折叠事件，查询
  当时的课程归属、支持决定与权益余额。

## 代码结构

- `contracts/domain.schema.json`：事件信封与全部事件类型约定。
- `data/sample.json`：中文联调样例。
- `src/validator.py`：基础事件信封校验。
- `src/continuity/clock.py`：可控、单调、不可回拨的业务时钟。
- `src/continuity/events.py`：不可变事件、事件类型与内容指纹。
- `src/continuity/store.py`：按聚合版本追加的事件存储，支持 JSONL 持久化
  与服务重启恢复。
- `src/continuity/model.py`：事件折叠读模型（支持任意历史时点）。
- `src/continuity/service.py`：中断接续应用服务（发布/报名/暂停/迁移/
  方案确认/待核/候补提升/幂等）。
- `tests/`：全场景测试。

## 测试覆盖

- 历史时点查询课程归属、支持决定与权益余额；
- 暂停后分批迁移（席位/名额只换位一次、补贴逐批守恒、成果带入）；
- 照护人更换与授权有效期边界；
- 截止点释放逾期席位并按固定顺位提升候补（队首被补贴名额阻塞时不跳过）；
- 服务重启后未决方案仍可确认、重放仍被去重；
- 并行确认意见不一致进入待核、一致则直接成立。

## 本地检查

```bash
python3 -m unittest discover -s tests
python3 -m compileall -q src tests
```

不需要外部基础设施；持久化测试使用临时 JSONL 文件。
